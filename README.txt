# IELTS Reading Practice Hub v2.0

## Run
1. Extract the ZIP file.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in a modern browser.

An internet connection is only needed for the optional Google Fonts; the app itself runs locally.

## What's included
- Three original Academic-style reading passages (about 2,186 words combined).
- 40 questions across three passages.
- 60-minute countdown based on a fixed deadline.
- Automatic local progress saving and resume after refresh/reopen on the same browser/device.
- Question flagging and question-number navigation.
- Automatic submission when time expires.
- Raw score, correct/incorrect/blank totals, question-format breakdown and an indicative band estimate.
- Answer review with explanations.

## Important
This is an independent IELTS-style practice resource, not an official IELTS paper. Its band estimate is indicative only. Actual IELTS Academic Reading band thresholds can vary by test version. The original passages and questions are newly written for practice.

## Progress privacy
Answers and timer state are saved in the browser's localStorage on the device. They are not uploaded to a server. Clearing browser site data will remove the saved attempt.
